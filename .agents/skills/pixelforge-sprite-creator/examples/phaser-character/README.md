# phaser-character

Editable PixelForge project format1.0. Run the installed CLI validate on phaser-character.sprite.json, render entry0 if animated, then export a spritesheet or Phaser bundle. Coin is a six-frame16px spin; character is a four-frame32px walk; phaser-character adds idle/jump/attack and scoped game metadata. These examples are generated by PixelForge's own operations.
