# v0.6 implementation plan

Audio uses separate `@pixelforge/audio-core` and `@pixelforge/audio-exporters`
packages. Sprite schema 1.0 and the existing editor remain independent.

1. Define strict sound schema 1.0, bounded resources and exact DSP semantics.
2. Implement shared offline renderer, mathematical tests and deterministic WAV.
3. Register CLI audio commands and atomic structured edits; managed exports.
4. Add a dedicated browser audio workspace with playback and diagnostics.
5. Deliver portable audio skill, five editable demos and Phaser consumers.
6. Verify regressions, browser/Node consistency, independently decoded WAV,
   packaged installation, Phaser loading and representative performance.

Baseline: Windows, existing v0.5 worktree; `npm test`: 18 files, 70 tests passed.
Existing v0.5 modifications are preserved. No publication is authorized.

## Mathematical contract

Mono Float64 PCM, default 44100 Hz; samples = round(durationMs * rate / 1000).
Sample n represents time n/rate. Voices mix in document order; no implicit
normalization. Output clipping is explicit. Envelopes interpolate linearly and
hold their last value. A final boundary fade is explicit in the document.
Oscillator phase integrates instantaneous frequency, in cycles; saw and pulse
use PolyBLEP. Noise uses xorshift32-v1 with project seed and stable voice-ID hash.

Linear ODE: dz/dt=(-lambda+i*2*pi*f)z, exact exponential stepping.
Nonlinear ODE: dz/dt=(sigma+i*2*pi*f)z+(cReal+i*cImag)|z|z,
bounded RK4 substeps with explicit work and state limits. Resonators sum linear
damped modes. Instability fails with voice ID, rather than sanitizing samples.

Research: Stefanakis, Abel and Bergner (2015), DOI 10.1162/COMJ_a_00314;
Schuck Jr. et al. (2019), DOI 10.1007/978-3-030-16077-7_33, equation 33.8.
The latter is A*ln(1+x/B)+C*x for x>=0, and
-D*ln(1-x/E)+F*x for x<0. A,D are voltage scales, B,E current
scales, C,F resistances in the physical model. Normalized game coefficients
are dimensionless and do not claim calibrated circuit fidelity. Source PDFs
are local research inputs, not redistribution assets.

## Implementation checkpoint

All six phases are implemented. The isolated clean-source install, 102 tests,
builds, six-package pack, skill lifecycle checks and checksums passed. Independent
packed consumers and both supported Phaser versions loaded/played audio; the
browser workspace and original editor regressions passed. Exact evidence and
platform/listening limits are in [verification.md](verification.md).
Cross-engine floating-point transcendental functions may differ; byte identity
is a same-runtime contract. No commit, push, tag or publication was performed.
