# Keyboard shortcuts

| Key                  | Action                           |
| -------------------- | -------------------------------- |
| B                    | Pencil                           |
| E                    | Eraser                           |
| G                    | Four-connected fill              |
| L                    | Line                             |
| R                    | Rectangle                        |
| O                    | Ellipse                          |
| I                    | Selected-layer eyedropper        |
| Space + drag         | Pan viewport                     |
| Escape               | Cancel an active drawing gesture |
| Ctrl/Cmd + Z         | Undo                             |
| Ctrl/Cmd + Shift + Z | Redo                             |
| Ctrl/Cmd + S         | Download editable project JSON   |

Shortcuts are suppressed while typing in inputs, selects, text areas or editable text. Pointer drawing focuses the viewport so shortcuts resume after editing a numeric field. Buttons and inputs remain keyboard-focusable.
