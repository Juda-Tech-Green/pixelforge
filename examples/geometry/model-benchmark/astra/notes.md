# Astra trial

The direct workflow accumulated rest offsets, translated the trunk and left arm, and intersected two circles for each elbow or knee that needed to move. The hands and shoes retain their rest offsets from their endpoints. The geometry workflow uses three two-bone targets per pose, with endpoint rotation compensation. The scene adds four part-level dependencies.

A search for the scene part ID delimiter also exposed an existing workshop sprite layer order before the direct file was saved. The scene-order result therefore has prior example exposure. No model evaluator was run or scores consulted. This single rig and room do not measure general artistic quality.
