# Semantic pose fixture — v0.8.2

This small standard-humanoid fixture is separate from the Antigravity clerk
evaluation in `examples/clerk/`. It demonstrates a 0.65-strength slump, a right
hand automatically targeting a folder grip, and explicit palm/folder/front-overlay
ordering. The tiny wrist ellipse is supplied fixture geometry, not generated
finger anatomy. `create-fixtures.ts` records the inputs; do not rerun it over edits.

Runtime/package versions are 0.8.2. All request/asset formats remain 1.0 with
separate `pixelforge-semantic-pose` and `pixelforge-held-object` identifiers.
The folder uses the character palette, its own local grip/support anchors and a
world transform. No animation or detailed illustration is generated.

Run from the repository root:

```powershell
npm run cli -- capabilities --json
npm run cli -- capabilities --schema semanticPose
npm run cli -- doctor examples/semantic-pose/hold.semantic-pose.json --rig examples/semantic-pose/clerk.rig.json --library examples/semantic-pose/clerk.poses.json --object examples/semantic-pose/folder.object.json --json
npm run cli -- rig resolve-pose examples/semantic-pose/hold.semantic-pose.json --rig examples/semantic-pose/clerk.rig.json --library examples/semantic-pose/clerk.poses.json --object examples/semantic-pose/folder.object.json --out examples/semantic-pose/resolved.pose.json --out-rig examples/semantic-pose/resolved.rig.json --json
npm run cli -- rig render examples/semantic-pose/resolved.rig.json --pose examples/semantic-pose/resolved.pose.json --output examples/semantic-pose/resolved.png --sprite examples/semantic-pose/resolved.sprite.json
npm run cli -- preview examples/semantic-pose/resolved.sprite.json --out examples/semantic-pose/preview.png --json
```

Omit both output flags for read-only JSON resolution. Output files are protected
unless `--force` is explicitly selected. Inspect reach diagnostics before rendering.
If using the optional secondary grip, add `secondaryGrip: {hand: "left", anchor:
"support"}` to attachment and review its residual as well.

Resolved poses are ordinary existing pose artifacts. For a held prop, render with
the returned derived rig; the source rig is unchanged. Contact sheets are available
after explicitly creating an ordinary sprite animation through existing tools.

## Gaze and chest-relative placement (v0.8.2)

The additional `gaze-relative.semantic-pose.json` reuses these unchanged rig,
library and folder sources. It positions the folder at chest-local offset [10,6]
with local rotation -0.2 radians, aligns the right wrist with its grip and aims
the head at the named support anchor. `[1,0]` explicitly declares this fixture's
head-local forward direction; no head/shoulder/elbow angle or absolute folder
position is required in the request. Runtime versions are 0.8.2.

```powershell
npm run cli -- capabilities --json
npm run cli -- capabilities --schema semanticPose
npm run cli -- rig resolve-pose examples/semantic-pose/gaze-relative.semantic-pose.json --rig examples/semantic-pose/clerk.rig.json --library examples/semantic-pose/clerk.poses.json --object examples/semantic-pose/folder.object.json --json
```

To render, append `--out gaze.pose.json --out-rig gaze.rig.json`, then use
`rig render gaze.rig.json --pose gaze.pose.json --output gaze.png --sprite gaze.sprite.json`
and `preview gaze.sprite.json --out gaze-preview.png --json`. Review hand residual
and gaze direction error before inspecting the PNG. Outputs require new paths or
explicit `--force`. Original Antigravity evaluation assets are not touched.

## Bounded anatomical comparison

`gaze-anatomical.semantic-pose.json` selects the new opt-in anatomical mode at
strength 1. It reuses the same source humanoid and folder and keeps the chest
placement, hand IK and sandwich ordering. Compare it with the existing
full-strength `gaze-relative.semantic-pose.json` (omitted mode means legacy).
Standard-skeleton defaults bound neck to [-0.2,0.2] and head to [-0.35,0.35]
radians. The low target intentionally leaves an honest rendered-direction
residual warning, rather than forcing a roughly 77-degree head rotation.

```powershell
npm run cli -- rig resolve-pose examples/semantic-pose/gaze-anatomical.semantic-pose.json --rig examples/semantic-pose/clerk.rig.json --library examples/semantic-pose/clerk.poses.json --object examples/semantic-pose/folder.object.json --json
```

Custom profiles belong in `gaze.anatomy`; limits intersect existing rig limits.
Read `gaze.anatomical` for per-joint deltas, limits and residual reasons. Eye aim
is not implemented. Use fresh `--out`/`--out-rig`, render and preview paths if
visual inspection is needed. Package versions are 0.8.2; no evaluation artwork
is regenerated by these read-only example commands.
