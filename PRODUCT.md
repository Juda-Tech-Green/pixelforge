# PixelForge

## Platform

web

## Stack

TypeScript, npm workspaces, React/Vite, Canvas 2D, Zod, Sharp, Commander, Vitest. Specified by the implementation brief.

## Users and purpose

Coding agents create deterministic, structured pixel art for 2D games. Developers inspect and import the same projects in a browser. Projects remain editable rather than becoming unrelated generated bitmaps.

## Capabilities and constraints

The foundation supplies a headless graphics API, JSON format, CLI, fixed-cell spritesheet export, and a minimal preview. No backend, cloud, authentication, paid service, or external image generation. Browser preview supports import, animation selection, playback, frame selection and zoom. Phase 2 supplies direct drawing, editable animations, onion skins, layer/palette management, bounded history and browser saving/export.

## Brand commitments

Clean, responsive developer-tool aesthetic, similar in spirit to lightweight graphics and code editors, as specified in the brief. No existing visual assets.

## Principles

Agent-first, human-editable, deterministic, open-source. Core logic stays independent of browser and Node adapters.
